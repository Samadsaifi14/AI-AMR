Use free-for.dev with a specific need

free-for.dev and its repository catalogue services with free tiers; they are not an inference engine or an installable application dependency. The current app uses local computing and the existing GitHub/Vercel publication.

For collaborators, start with GitHub source/version tracking, institution-approved file exchange, and local Python. Browser training has no paid inference API. Do not add a database just to connect the frontend: the worker already calls the same Python modules as the CLI.

Before adding hosted compute or storage, check the provider's current terms, quotas, data location and institutional permission. A listed free tier is not unlimited, permanent or automatically suitable for patient data. No new hosted account or paid add-on was created in this update.

GitHub Actions documentation · Vercel Hobby terms · Colab FAQ. Colab is optional development infrastructure, not a clinical-data destination or a deployed backend.

For the next developer

Change endpoint/panel/split parameters in configuration, data import in the canonical Python modules, and presentation in the web directory. Keep the browser bridge thin. Run the existing checks after changes and package current source at build time.
