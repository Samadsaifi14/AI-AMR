Three-fold grouped model selection → held-out calibration → locked test. Split modes: internal, source, country, temporal. Target-drug and other carbapenem features are blocked. The public pilot permits unversioned reported labels and is not breakpoint-harmonized.

How the free runtime works

Python, pandas and scikit-learn run in a dedicated browser worker using Pyodide 0.29.3. The first run downloads scientific packages from jsDelivr. Uploaded files and fitted models stay in memory on this device. Closing the tab discards them; download your bundle first. There is no shared server database. Use desktop Chrome, Firefox or Edge for larger runs.

These pilots selected different models independently. Their difference is not a paired estimate of one model's degradation. Original reports and exact source tables are in the code bundle. Local and browser package versions can select different models; each run records its runtime.
  • NCBI BioSample antibiograms — submitter-provided measured AST. Convenience acquisition, not national sampling.
  • MALCA, Nature Communications (2026) — a carbapenemase detection/type endpoint; access controls respected.
  • Related ATLAS study (2025) — source-study methods reviewed separately from this AST model.
  • Indian surgical ICU study (2026) — public supplements acquired: 122 patient AST rows (115 R / 6 S / 1 I), 854 curated candidate observations, 2,162 raw positive gene calls. Standard/units and 114 proposed ID joins require review; quarantined from training.
  • Multicentre Indian genomic profiling study — resistance-selected cohort; useful mechanism evidence, inadequate alone for population discrimination.
  • Pyodide runtime documentation — pinned browser compute; no paid inference service.
Scope: bacterial resistance research. The lab does not infer a person's genetics, ethnicity or health from geography, and its models are not clinically validated. Free software removes subscription/API costs; data collection, validation and your device's compute may still require resources.
