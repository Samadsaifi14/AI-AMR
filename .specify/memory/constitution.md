# AI-AMR Constitution

1. Measured laboratory AST supplies outcome evidence. MIC bounds, units and original interpretation metadata remain explicit; missing measurements are never invented.
2. Development selects preprocessing, predictor panels, models and thresholds. Evaluation stays separate. Repeatedly inspected public cohorts are retrospective evidence.
3. Browser and CLI call the same Python modules. Configuration changes and new batches do not require a second pipeline or redesign.
4. Guides explain input preparation, errors, limitations and export. Research estimates must never be described as clinical susceptibility or established Pune accuracy.
5. Private inputs remain on-device or in ignored local folders. Source packaging excludes private inputs, credentials and joblib models.
6. Completed changes require relevant software, integration and UI verification. Report unresolved accuracy and deployment limitations honestly.
